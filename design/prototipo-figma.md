# Protótipo Figma — Dashboard

- **Arquivo:** Prototipo_Projeto_Web
- **Página:** 01 — Discovery e Interface
- **Frame:** Dashboard — Desktop
- **Estado:** protótipo visual concluído

## Componentes da tela

1. Cabeçalho e navegação;
2. Título e descrição do painel;
3. Painel de filtros;
4. Busca por palavra-chave;
5. Cabeçalho da tabela;
6. Quatro linhas de exemplo estrutural;
7. Paginação.

## Colunas da tabela

- Órgão responsável;
- Investimento / Projeto;
- Localidade;
- Valor previsto;
- Valor executado;
- Situação.

## Observações para desenvolvimento

- Os dados mostrados nas linhas do protótipo são placeholders;
- Os controles são representações visuais e precisam de implementação;
- O protótipo não define ainda a API, o modelo de dados nem a fonte de cada campo;
- Consultar o arquivo Figma para medidas, estilos e hierarquia de componentes.
